# Post-0.1.0 Qualification

## Muxy SSH workspaces

GSD Control Tower 0.1.0 is qualified only with local macOS workspaces in Muxy 1.5.0 (945). Do not advertise SSH-workspace support based solely on the brokered projects, files, worktrees, agents, or Git APIs.

Before adding SSH support to the marketplace claim, qualify the native Muxy flow end to end: remote project discovery, permission prompts, artifact reads, worktree switching, Git state, agent events, reconnect/offline behavior, panel close/reopen, and application restart. Record the Muxy build, remote topology, expected degradation, and privacy review.
