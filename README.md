# Muxy Extensions

The marketplace for [Muxy](https://muxy.app) extensions.

Each published version is a GitHub Release tagged `<name>@<version>`, and is
also uploaded to [muxy.app](https://muxy.app), which lists it on the website.
The app reads the listing from `index.json` on the `index` branch.
